How It Works

• Session Lifetime: All users (including admins) stay logged in for this duration. After it expires, they need to log in again.

• Admin Re-auth: Even if an admin's session is still valid, they must re-login to make administrative changes if this time has passed since their last login.

• This adds an extra layer of security: long sessions for convenience, but fresh re-auth for sensitive actions.

Media Transcoding

Some video formats (like HEVC/H.265 from iPhone) won't play on all devices. Transcoding converts them to H.264/MP4 which works everywhere.

Scan & Transcode

Scans all media files for incompatible formats and converts them. New uploads are transcoded automatically — use this only for legacy files or imported backups.

Videos are auto-transcoded to H.264 on upload. iPhone HEIC photos are auto-converted to JPEG on upload.

Storage Settings

When transcoding, should the original files be kept?

Keeping originals uses more storage but preserves quality and allows you to retrieve original files later. Disabling this will delete originals after successful transcoding to save space.

Recurring Events

Yearly events get a new instance automatically (checked every 6 hours). Use this to create them right now.

⚠️ Warning: Original files will be deleted

Once you disable "Keep originals", transcoded videos will replace the original files permanently. This cannot be undone.
